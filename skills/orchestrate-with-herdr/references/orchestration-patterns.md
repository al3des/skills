# Orchestration patterns

Read the pattern matching Matt's dependency plan.

## Sequential work

For a dependency chain, route and launch the first unit before later units. Wait on its named agent, verify its acceptance evidence, and run its acceptance command. Then route the unlocked unit, create its tab, and give its fresh session the concise prior handoff. Preserve product-intent questions as HITL decisions.

## Parallel work

For independent units, route every unit before creating tabs, then start one fresh worker in each clearly named tab. Monitor lifecycle state independently. Feed an investigation's relevant finding only to work it unlocks; continue unaffected independent work. Preserve blocked HITL work while validating each unit's acceptance evidence and the combined goal.
